## ② AIへの指示文（プロンプト）全文

### 設計方針

- AIの役割（英検4級対策専門コーチ「コーチAI」）・口調（やわらかい敬体／1文は短く／中学生に届く言葉）・出力フォーマット（JSON）を明確に定義。
- **級のレベルを明文化して縛る**。使ってよい文法・語彙・英文の長さを列挙し、英検4級（中学中級程度）を超えさせない。
- 単語データ（英単語・品詞・意味・難易度・**日常場面**・**混同しやすい類似語**）と、**ユーザーが選んだ誤答の語とその品詞**を必ずセットで渡す。
- さらに **これまでの弱点タイプ1位** と **復習キューからの再出題か** を渡し、セッションを跨いで一貫したコーチングにする。
- 誤答理由を **4タイプの列挙値** で返させ、アプリ側の弱点集計キーと1対1で対応させる。
- 出力は構造化出力（zodスキーマ）でJSON形状を強制。

### 共通：学習者ペルソナ（全プロンプトが内包）

```
【学習者プロフィール】
- 中学2年生。次の英検4級に合格したい。
- 学習時間は部活のあとの15分と、寝る前の10分だけ。
- 英語は嫌いではないが、単語がなかなか覚えられず自信がない。「今日やった分だけ合格に近づいている」と実感したい。
```

### 共通：英検4級レベルを守らせるルール（全プロンプトが内包）

```
【英検4級レベルを守るルール】
- 英文は中学2年生が読める長さ・語彙にする（10語前後、長くても15語まで）。
- 使ってよい文法は、be動詞 / 一般動詞の現在・過去形 / 現在進行形 / 助動詞(can, will, must) / 不定詞 / 動名詞 / 接続詞(and, but, because, when) / 比較 まで。
- 難しい単語（英検3級以上の語）は使わない。固有名詞は Tom, Ken, Emi など短い人名にとどめる。
- 説明の日本語も中学生に伝わる言葉づかいにし、漢字は中学生が読める範囲にする。
```

### プロンプト1：1問ごとのフィードバック（システムプロンプト）

```
あなたは英検4級対策専門の英語コーチ「コーチAI」です。中学生の学習者を、短い言葉で的確に、そして前向きに励ましながら指導します。

【学習者プロフィール】（上記）

【あなたの役割】
- 学習者が解いた1問について、日本語でフィードバックを返す。
- 一般論や教科書的な説明は禁止。必ず「その単語・その誤答・その場面」に即した具体的な内容にする。
- 口調はやわらかい敬体（です・ます）。1文は短く、スキマ時間でもすぐ読める分量にする。
- 決して見下さず、「間違えた＝伸びしろが見つかった」という姿勢で書く。

【英検4級レベルを守るルール】（上記）

【誤答タイプ（error_type）の選択肢】必ず次の4つのいずれかを英字キーで返すこと。
上から順に判定し、最初に当てはまったものを選ぶこと。
- "confusion": 意味が近い語と取り違えた。similar に挙がっている語の意味を選んだ場合か、正解の訳語と選んだ訳語が部分的に重なる場合（例:「借りる」と「貸す」、「持ってくる」と「持っていく」）。
- "pos": 品詞がまったく重ならない語の意味を選んだ（例: 出題語が動詞で、選んだ意味は名詞のみの語）。
- "scene": 品詞は重なるが、同じ日常場面（学校・買い物・おでかけなど）で使う語どうしを取り違えた。
- "memory": 上記のいずれにも当てはまらず、単純にまだ記憶が定着していない。

【出力するJSONの各項目の指示】
- error_type: 不正解のときだけ上記4つから1つ選ぶ。正解のときは "memory" ではなく空文字 "" を返す。
- reason: 不正解のときだけ書く（正解のときは空文字 ""）。選んだ error_type の観点から、なぜ間違えたのかを渡された「類似語」「品詞」「日常場面」を手がかりに説明する。「〇〇と混同したかもしれません。△△との違いは〜」のように1〜2文。責めず、次に活かせる形で。
- example_en: その単語を使った英文を1文。必ず渡された「日常場面」で中学生が実際に出会いそうな、英検4級の短文問題に出てきそうな文にする。
- example_ja: example_en の自然な日本語訳。
- tip: 覚えるため・使えるようになるための一言ヒント（1文）。似た語との違い、よく一緒に使う語（go to / listen to など）、英検4級での出やすい形など、試験で直接役に立つ内容にする。
```

### 呼び出し設定

- `client.messages.parse()` ＋ `output_config.format`（zod構造化出力）でJSON形状を保証。

## ③ 制作メモ

### どんな体験を作ろうとしたか

英検4級を目指す中学2年生・ゆうとくんが、部活のあとの15分と寝る前の10分で「今日やった分だけ合格に近づいている」と実感できる学習アプリ **WordBoost 4級** を作りました。既存アプリで多くの人が挫折する3つの構造的課題（①覚えた→使えない ②間違えた→理由が不明 ③続けたのに実感がない）すべてに、明確なアンサーを用意しています。

そのうえで軸にしたのは **「合格に必要なものを全部入れる」** ことです。英検4級は筆記35問・リスニング30問で、**リスニングが3分の1近く**を占めます。単語アプリだけでは合格に必要な力の一部しかカバーできないため、**本番の全出題形式**をモードとして実装しました（上記①の表）。

### 選んだ出題形式と、その理由（必須項目）

**中心の出題形式は「英単語 → 意味を4択（誤答に『混同しやすい類似語』の意味を優先的に混ぜる）」** を選び、そこから本番の全形式へ広げました。

理由は3つあります。第一に、**4択はスキマ時間で片手・数秒で解答できる**ため、ゆうとくんの利用状況（部活後・寝る前・10〜15分）に最も適しているからです。第二に、**単語データの `similar`（混同しやすい類似語）と `example_scene`（日常場面）を誤答生成のスコアリングに使う**ことで、意味の精密な識別を迫る良問を動的に作れるからです（類似語＝6点、訳語の部分一致＝5点、固有性の高い場面タグ一致＝3点、品詞の重なり＝1点で加点し、上位3つを誤答に採用）。英検4級は `borrow / lend`、`bring / take` のように**対になる語の取りちがえ**が頻出なので、この設計がそのまま得点に効きます。第三に、**入力の手間を最小化することで、学習体験の主役を「解答」ではなく「解答後のコーチング」に置ける**からです。

なお、4択の弱点である「選べたが使えない」を潰すため、解答直後に**同じ単語を例文の穴埋めで再提示**しています。この穴埋めは**大問1（短文の語句空所補充）とまったく同じ形式**なので、「使えるかの確認」がそのまま試験対策になります。

### AIをどう使うか設計した意図

**「AIが間違いを4タイプに分類し、その分類がアプリ全体を動かす」** ことを設計の中心に置きました。

Claudeには単に解説を書かせるのではなく、誤答を必ず **`confusion`（似た意味の語と混同）/ `pos`（品詞の取りちがえ）/ `scene`（場面のイメージちがい）/ `memory`（まだ覚えきれていない）** の4タイプの列挙値で返させ、アプリ側の集計キーと1対1で対応させています。この構造化された分類が、(1) その場のフィードバック文の切り口、(2) ホーム画面の**弱点プロフィール**（4タイプの累積内訳バー）、(3) 次回セッションの**総括プロンプトへの入力**（「これまでの弱点1位は〇〇です」）という3か所を横断して駆動します。つまり **セッションを跨いでコーチが自分を覚えている** 状態を作りました。

もう一つ重視したのが、**「級のレベルを明文化して縛る」** ことです。生成AIは放っておくと大人向けの英文を書いてしまい、4級の学習者には難しすぎる例文が混ざります。そこで全プロンプトに「英文は10語前後・長くても15語」「使ってよい文法の列挙」「英検3級以上の語は使わない」を明記しました。

### 発音・リスニングをどう実現したか

リスニングが3分の1を占める以上、**音がないアプリは4級対策として不完全**です。かといって録音されたネイティブ音源はライセンス費用が発生し、「実行時コスト0円」という方針と両立しません。

そこで**ブラウザ標準の Web Speech API** を使い、端末に入っている音声から**ネイティブ品質の en-US 音声**（Google US English / Microsoft の Natural 音声 / Apple の Samantha など）を名前で優先選択する実装にしました。追加のAPIキーも通信も不要で、費用は0円、オフラインでも鳴ります。🐢ボタンで0.65倍速の再生もできます。リスニングモードでは**本文を一切表示せず**、第1部は**選択肢も音声のみ**にして、本番と同じ条件にしています。

### 作る中で変えた判断

**判断1：スマホアプリ（Expo）→ Next.jsのWebアプリに作り直した。** 審査のしやすさ（URLで即動作確認）とAPIキーの安全管理（サーバー側の環境変数に隠す）を優先しました。

**判断2：例文とヒントを「実行時生成」から「事前生成（プリベイク）」に変えた。** 当初は毎問Claude APIで例文を生成していましたが、(a) 従量課金が発生する、(b) 解答のたびに数秒待たされテンポを壊す、という2つの問題がありました。そこで**300語すべての例文・和訳・ヒントをClaudeに事前一括生成させてJSONで同梱**し、実行時は即座に返す方式に変更しました。会話・語句整序・長文・リスニングも同様に**解説つきで事前生成**しています。結果、**実行時のAPIコストは0円、表示は待ち時間ゼロ**になりました。

**判断3：APIキーが無くても全機能が動くようにした。** 誤答タイプ判定はローカルロジックでも成立するよう実装し、フィードバック文・総括文もローカルで組み立てられるようにしました。`ANTHROPIC_API_KEY` を設定すればその出力をClaude APIの応答が上書きする二層構造です。AIが落ちてもアプリは止まりません。

**判断4：誤答タイプの判定ロジックを、実データのシミュレーションで作り直した。** 当初は「`similar` に相手の語が載っているか」「場面文字列が完全一致か」で判定していましたが、300語で分布を測ると誤答の大半が「まだ覚えきれていない」に落ち、弱点プロフィールが機能しませんでした。そこで判定材料を「訳語の部分一致（借りる ⇔ 貸す）」「品詞の集合比較（名詞/動詞 と 動詞/名詞 は同一とみなす）」「固有性の高い場面タグの一致」に組み替えました。場面タグは `学校・図書室` のように **〈大分類・小分類〉** で持たせ、`学校`（44回）`おでかけ`（40回）のように多くの語が共有する大分類19個は根拠として弱いので除外し、固有な小分類125個だけを使っています。

**判断5：語形変化の照合を、前方一致から「取りうる形を作って完全一致」に作り直した。** 旧実装（語幹の前方一致）は `cry → cried` や `save → saving` を拾えず、逆に `play` が `player` を隠してしまう危険がありました。英検4級は**不規則動詞の過去形が出題範囲**なので、例文でも `bought / went / wrote` を積極的に使いたい。そこで不規則動詞58語・不規則複数形8語の表と規則変化の機械生成を実装し、**その語が取りうる形をすべて作ってから語として完全一致で探す**方式に変えました。`stop → stopped` のように語尾を重ねるかはつづりだけでは決まらない（`visit → visited` は重ねない）ため、両方を候補に入れて当たった方を採用します。これで**全300語で穴埋めが作れる**ことを自動検証しています。

### 3つの課題への具体的なアンサー

- **① 覚えた→使えない**：解答直後、その語を空欄にした例文を提示（例：`I ______ my bike to the park.`）。これは大問1と同じ形式なのでそのまま試験対策になります。タップで答えと和訳を開示し、🔊で発音も確認できます。正解者にも必ず出します。
- **② 間違えた→理由不明**：誤答を4タイプに自動分類し、タイプ別の切り口で理由を説明。「lend と混同したようです。borrow は「借りる」で…」のように、その語・その誤答に固有の文言になります。語彙以外のモードも1問ずつ解説つきです。
- **③ 続けたのに実感なし**：4級合格到達度メーター（語彙カバー率4割＋筆記の正解率3.5割＋リスニングの正解率2.5割）、覚えた単語 N/300、技能別の仕上がりバー、連続学習日数、弱点プロフィールの内訳バーを常時表示します。重みは本番の配点（筆記35問・リスニング30問）に「語彙はすべての土台」という点を加味して決めました。

### 独自性（このアプリでないと体験できないこと）

- **4級の全出題形式が1つのアプリに揃っている。** 大問1〜4とリスニング第1〜3部を、それぞれ本番と同じ条件（リスニングは本文非表示、第1部は選択肢も音声のみ）で練習でき、実戦ミニ模試で通しの実力も測れます。
- **弱点タイプの可視化と、それによる出題制御。** 「何問正解したか」ではなく「**どう間違えるクセがあるか**」を4タイプで蓄積・可視化し、次のセッションのAIコーチの言葉にまで反映させます。
- **復習キューによる強制再会。** 間違えた語はIDで保持され、**次のセッションで「📌 復習」バッジ付きで再登場**します（最大3語を先頭に固定）。正解できて初めてキューから外れます（間隔反復ライト）。
- **プリベイク＋ブラウザ音声によるゼロコスト設計。** 「AIを使う＝毎回APIを叩く」「音声＝音源を買う」という前提を両方外し、質を保ったままコストと待ち時間を消しました。

### 収録データ

英検4級レベル単語300語（うち空所補充に使える語229語）／ 会話30問 ／ 語句整序24問 ／ 長文5題15問 ／ リスニング20問。

### 使用ツール

Claude Code（設計・実装・コーチパックと問題データの事前生成）／ Next.js 16（App Router）／ Claude API（`claude-haiku-4-5`・構造化出力）／ Web Speech API（発音・リスニング）／ Vercel（ホスティング）。学習進捗は localStorage に保存し、サーバーもDBも不要にしています（運用コスト0円）。
