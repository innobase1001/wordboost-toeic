# WordBoost 4級 — 英検4級 合格アプリ（DMM生成AI CAMP 第8回コンペ）

英検4級の出題形式を**すべて**カバーし、AIコーチが「**なぜ間違えたか**」を4タイプに分類して教えてくれる、
中学生向けのスキマ学習アプリです。Next.js（App Router）＋ Claude で実装しています。

## 英検4級の試験構成と、アプリの対応

| 本番の出題 | 問題数 | 対応モード |
| --- | --- | --- |
| 筆記 大問1 短文の語句空所補充 | 15問 | ✏️ **空所補充** |
| 筆記 大問2 会話文の文空所補充 | 5問 | 💬 **会話** |
| 筆記 大問3 日本文付き語句整序 | 5問 | 🔀 **並べかえ** |
| 筆記 大問4 長文の内容一致選択 | 10問 | 📄 **長文**（掲示・Eメール・説明文） |
| リスニング 第1部 会話の応答文選択 | 10問 | 🎧 **リスニング**（音声のみで応答を選ぶ） |
| リスニング 第2部 会話の内容一致選択 | 10問 | 🎧 **リスニング** |
| リスニング 第3部 文の内容一致選択 | 10問 | 🎧 **リスニング** |
| （すべての土台） | — | 📖 **単語**（4択・AI誤答分析つき） |
| 本番と同じ流れで通し | 18問 | 📝 **実戦ミニ模試** |

## 3つの構造的課題へのアンサー

| 課題 | 実装 |
| --- | --- |
| **① 覚えた→使えない** | 解答直後、その語を空欄にした例文の穴埋めを提示。これは大問1とまったく同じ形式なので、そのまま試験対策になります |
| **② 間違えた→理由不明** | 誤答を **似た意味の語と混同 / 品詞の取りちがえ / 場面のイメージちがい / まだ覚えきれていない** の4タイプに自動分類し、タイプ別の切り口で理由を説明 |
| **③ 続けたのに実感なし** | 4級合格到達度メーター・覚えた単語 N/300・技能別の仕上がりバー・連続学習日数・弱点プロフィールを常時表示 |

さらに、間違えた語は**復習キュー**に入り、次セッションで「📌 復習」バッジ付きで再登場します
（最大3語を先頭に固定）。正解できて初めてキューから外れます。

### 4級合格到達度の計算

```
到達度 = 語彙カバー率 × 0.4 + 筆記の正解率 × 0.35 + リスニングの正解率 × 0.25
```

本番の配点（筆記35問・リスニング30問）に、語彙はすべての土台という点を加味した重みです。
まだ解いていない区分は0として扱うので、練習した分だけ数字が伸びます。

## 発音・リスニング（追加費用0円）

リスニングは4級の3分の1を占めるため、単語も例文も会話も**音とセット**で学べるようにしています。

- ブラウザ標準の **Web Speech API**（`lib/speech.js`）を使用。追加のAPIキーも通信も不要です。
- 端末に入っている音声から、**ネイティブ品質の en-US 音声**（Google US English / Microsoft の Natural 音声 /
  Apple の Samantha など）を名前で優先選択します。見つからなければ en-US → en-GB → その他の英語の順。
- 🐢 ボタンで **0.65倍速**の再生ができます（聞き取れなかったときの2回目用）。
- リスニングモードでは本文を表示しません。第1部は**選択肢も音声のみ**で、本番と同じ形式です。

> 録音されたネイティブ音源ではなく、端末の音声合成による読み上げです（音源のライセンス費用が
> かからないため、実行時コスト0円という設計方針を保てます）。発音・イントネーションはネイティブ準拠です。

## 出題ロジック

**語彙4択**の誤答は、`similar`（混同しやすい類似語＝6点）、訳語の部分一致（＝5点）、
固有性の高い日常場面タグの一致（＝3点）、品詞の重なり（＝1点）でスコアリングして動的に生成します。
重みは英検4級300語でのシミュレーションで、誤答タイプが4種に偏りなく分かれる値を選びました（`lib/modes.js`）。

**空所補充**は、例文の中に原形そのままで出てくる語（229語）だけを使い、
同じ品詞の語を優先して誤答にします。活用形の照合には `lib/inflect.js` を使っています
（不規則動詞58語・不規則複数形8語の表＋規則変化の機械生成）。

## AIの二層構造（実行時コスト0円）

```
┌─ 事前生成（プリベイク） ────────────────────────────┐
│ 300語分の例文・和訳・実践ヒントを Claude が生成            │
│ → data/coach_pack.json に同梱（実行時API呼び出しなし）     │
│ 会話・並べかえ・長文・リスニングは解説をデータに同梱        │
└──────────────────────────────────────────────┘
┌─ 実行時 ────────────────────────────────────────┐
│ ANTHROPIC_API_KEY あり → Claude API が誤答分析・総括を生成 │
│ ANTHROPIC_API_KEY なし → ローカルコーチが同じ形式で生成    │
└──────────────────────────────────────────────┘
```

**APIキーを設定しなくても全機能が動作します**（費用0円）。キーを設定した場合のみ、
語彙モードの誤答分析とセッション後の総括が Claude API のリアルタイム生成に切り替わります。

## セットアップ（ローカル）

```bash
cd web
npm install
npm run dev                  # http://localhost:3000
```

Claude API を使いたい場合のみ:

```bash
cp .env.example .env.local   # .env.local に ANTHROPIC_API_KEY を記入
```

- `ANTHROPIC_API_KEY` は `console.anthropic.com` で発行（**Claude Pro/Maxのサブスクとは別課金**）。
- モデルは既定で `claude-haiku-4-5`（`ANTHROPIC_MODEL` で変更可）。

## Vercelへのデプロイ

1. このリポジトリを GitHub に push（`.env.local` は `.gitignore` 済み）。
2. Vercel で Import。**Root Directory は `web`** を指定。
3. （任意）Environment Variables に `ANTHROPIC_API_KEY` を設定。**未設定でも動きます。**
4. Deploy → 発行された URL を提出。

## リポジトリ内の `src/`・`App.js` について

リポジトリ直下の `src/` と `App.js` は、**作り始めた当初の Expo（React Native）版プロトタイプ**です。
提出対象のアプリは `web/` 配下のみで、Expo版はビルドにも動作にも関与しません
（制作メモの「判断1」で Web に切り替えた経緯を記載しています）。経緯を残す目的で同梱しています。
