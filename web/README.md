# WordBoost — TOEIC 700点 英単語アプリ（DMM生成AI CAMP 第8回コンペ）

AIコーチが「**なぜ間違えたか**」を4タイプに分類して教えてくれる、社会人向けスキマ英単語アプリです。
Next.js（App Router）＋ Claude で実装しています。1回10問・数分で完了します。

## 3つの構造的課題へのアンサー

| 課題 | 実装 |
| --- | --- |
| **① 覚えた→使えない** | 解答直後、その語を空欄にした**ビジネス例文の穴埋め**を提示。タップで答えと和訳を開示（正解者にも必ず表示） |
| **② 間違えた→理由不明** | 誤答を **類似語の混同 / 品詞の取り違え / 場面イメージ違い / 記憶が薄い** の4タイプに自動分類し、タイプ別の切り口で理由を説明 |
| **③ 続けたのに実感なし** | 700点到達度メーター・学習済み N/300・累計正解率・連続学習日数・**弱点プロフィールの内訳バー**を常時表示 |

さらに、間違えた語は**復習キュー**に入り、次セッションで「📌 復習」バッジ付きで再登場します
（最大3語を先頭に固定）。正解できて初めてキューから外れます。

出題形式は「英単語 → 意味の4択」。誤答の選択肢は、`similar`（混同しやすい類似語＝6点）、
訳語の部分一致（＝5点）、固有性の高いビジネス場面タグの一致（＝3点）、品詞の重なり（＝1点）で
スコアリングして動的に生成します。重みは支給300語でのシミュレーションで、
誤答タイプが4種に偏りなく分かれる値を選びました（`lib/similarity.js`）。

## AIの二層構造（実行時コスト0円）

```
┌─ 事前生成（プリベイク） ────────────────────────────┐
│ 300語分のビジネス例文・和訳・実践ヒントを Claude が生成    │
│ → data/coach_pack.json に同梱（実行時API呼び出しなし）     │
└──────────────────────────────────────────────┘
┌─ 実行時 ────────────────────────────────────────┐
│ ANTHROPIC_API_KEY あり → Claude API が誤答分析・総括を生成 │
│ ANTHROPIC_API_KEY なし → ローカルコーチが同じ形式で生成    │
└──────────────────────────────────────────────┘
```

**APIキーを設定しなくても全機能が動作します**（費用0円）。キーを設定した場合のみ、
1問ごとの誤答分析と10問後の総括が Claude API のリアルタイム生成に切り替わります。

## セットアップ（ローカル）

```bash
cd web
npm install
npm run dev                  # http://localhost:3000
```

Claude API を使いたい場合のみ:

```bash
cp .env.example .env.local   # .env.local に ANTHROPIC_API_KEY を記入
```

- `ANTHROPIC_API_KEY` は `console.anthropic.com` で発行（**Claude Pro/Maxのサブスクとは別課金**）。
- モデルは既定で `claude-haiku-4-5`（`ANTHROPIC_MODEL` で変更可）。

## Vercelへのデプロイ

1. このリポジトリを GitHub に push（`.env.local` は `.gitignore` 済み）。
2. Vercel で Import。**Root Directory は `web`** を指定。
3. （任意）Environment Variables に `ANTHROPIC_API_KEY` を設定。**未設定でも動きます。**
4. Deploy → 発行された URL を提出。

## 構成

```
web/
├─ app/
│  ├─ page.js              ホーム／クイズ／結果（クライアント）
│  ├─ layout.js            メタ情報
│  ├─ globals.css          UI
│  └─ api/
│     ├─ feedback/route.js 1問ごとのフィードバック（誤答分類＋例文＋ヒント）
│     └─ summary/route.js  10問後の学習総括
├─ lib/
│  ├─ words.js             出題ロジック（4択＋類似語ダミー＋復習キュー優先）
│  ├─ coach.js             オフラインAIコーチ（誤答タイプ判定・例文取得・総括）
│  ├─ errorTypes.js        誤答4タイプの定義（サーバー／クライアント共通）
│  ├─ prompts.js           Claudeへの指示文（提出物②の実体）
│  ├─ claude.js            SDKクライアント／モデル設定
│  └─ progress.js          学習進捗（localStorage・弱点集計・復習キュー）
├─ data/
│  ├─ toeic_wordlist.json  運営配布の300語（改変なし）
│  └─ coach_pack.json      Claude事前生成の例文・和訳・ヒント（300語）
└─ docs/                   提出用ドキュメント（プロンプト全文・制作メモ）
```

## リポジトリ内の `src/`・`App.js` について

リポジトリ直下の `src/` と `App.js` は、**作り始めた当初の Expo（React Native）版プロトタイプ**です。
提出対象のアプリは `web/` 配下のみで、Expo版はビルドにも動作にも関与しません
（制作メモの「判断1」で Web に切り替えた経緯を記載しています）。経緯を残す目的で同梱しています。
