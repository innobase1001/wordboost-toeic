# WordBoost — TOEIC 700点 英単語アプリ

**DMM生成AI CAMP 第8回コンペ 提出作品**

誤答を4タイプに自動分類し、「なぜ間違えたか」まで教えてくれる社会人向けスキマ英単語アプリです。
1回10問・数分で完了します。

## 特徴

- **誤答を4タイプに分類** — 類似語の混同 / 品詞の取り違え / 場面イメージ違い / 記憶が薄い。
  分類結果はホーム画面の「弱点プロフィール」に蓄積され、次回のコーチの言葉にも反映されます。
- **復習キュー** — 間違えた語は次のセッションで「📌 復習」バッジ付きで再登場し、正解して初めて外れます。
- **ビジネス例文の穴埋め** — 解答直後に同じ語を空欄にした例文を提示し、「覚えた」を「使える」に変えます。
- **APIキー無しでも全機能が動作** — 300語分の例文・ヒントを Claude で事前生成して同梱しているため、
  実行時のAPIコストは0円です。`ANTHROPIC_API_KEY` を設定した場合のみ、誤答分析と総括が
  Claude API のリアルタイム生成に切り替わります。

## ローカルで動かす

```bash
cd web
npm install
npm run dev   # http://localhost:3000
```

## ディレクトリ構成

```
.
├─ web/                 提出対象のWebアプリ（Next.js）
│  ├─ app/              画面とAPIルート
│  ├─ lib/              出題・誤答分類・進捗・プロンプト
│  ├─ data/             支給された300語 + Claude事前生成のコーチパック
│  └─ docs/             提出用ドキュメント
├─ src/, App.js         当初のExpo（React Native）版プロトタイプ ※提出対象外
└─ README.md            このファイル
```

`src/` と `App.js` は、Webアプリに切り替える前の Expo 版プロトタイプ（40語・フラッシュカード＋4択、Claude連携なし）です。
**コンペの提出対象は `web/` 配下のみ**で、Expo版はビルドにも動作にも関与しません
（切り替えの経緯は制作メモの「判断1」に記載）。

## デプロイ構成（Vercel）

このリポジトリは2つのアプリを含むため、Vercelでは**別々のプロジェクト**として扱います。

| 対象 | Vercelの Root Directory | ビルド | 出力 |
| --- | --- | --- | --- |
| **提出用アプリ（Next.js）** | **`web`** | Next.js自動検出 | `.next` |
| Expo版プロトタイプ（任意） | `./`（ルート） | `expo export -p web`（ルートの `vercel.json`） | `dist` |

> ⚠️ Root Directory を `./` のままにすると、Expo版（＝提出対象外）が公開されます。
> 提出用URLを作るときは必ず **Root Directory に `web`** を指定してください。
