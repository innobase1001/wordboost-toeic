# WordBoost 4級 — 英検4級 合格アプリ

**DMM生成AI CAMP 第8回コンペ 提出作品**

🔗 公開URL: **https://wordboost-toeic.vercel.app/**

英検4級の出題形式を**すべて**カバーし、誤答を4タイプに自動分類して「なぜ間違えたか」まで教えてくれる、
中学生向けのスキマ学習アプリです。1モード数分で完了します。

## 英検4級の全出題形式に対応

| 本番の出題 | 対応モード |
| --- | --- |
| 筆記 大問1 短文の語句空所補充 | ✏️ 空所補充 |
| 筆記 大問2 会話文の文空所補充 | 💬 会話 |
| 筆記 大問3 日本文付き語句整序 | 🔀 並べかえ |
| 筆記 大問4 長文の内容一致選択 | 📄 長文（掲示・Eメール・説明文） |
| リスニング 第1部〜第3部 | 🎧 リスニング |
| （すべての土台） | 📖 単語（4択・AI誤答分析つき） |
| 本番と同じ流れで通し | 📝 実戦ミニ模試 |

## 特徴

- **誤答を4タイプに分類** — 似た意味の語と混同 / 品詞の取りちがえ / 場面のイメージちがい / まだ覚えきれていない。
  分類結果はホーム画面の「弱点プロフィール」に蓄積され、次回のコーチの言葉にも反映されます。
- **ネイティブ発音の読み上げ** — 単語・例文・会話・長文すべてに🔊ボタン。ブラウザ標準の音声合成を使い、
  端末のネイティブ品質 en-US 音声を優先選択します。🐢ボタンで0.65倍速再生も可能。**通信・費用ゼロ**です。
- **リスニングは本文非表示** — 第1部は選択肢も音声のみ。本番と同じ条件で練習できます。
- **復習キュー** — 間違えた語は次のセッションで「📌 復習」バッジ付きで再登場し、正解して初めて外れます。
- **4級合格到達度** — 語彙カバー率4割＋筆記の正解率3.5割＋リスニングの正解率2.5割の合成指標。
  技能別の仕上がりバーで、どこが弱いかがひと目で分かります。
- **APIキー無しでも全機能が動作** — 300語分の例文・ヒントを Claude で事前生成して同梱し、
  会話・整序・長文・リスニングは解説をデータに同梱しているため、実行時のAPIコストは0円です。
  `ANTHROPIC_API_KEY` を設定した場合のみ、語彙モードの誤答分析と総括が Claude API のリアルタイム生成に切り替わります。

## 収録データ

| 種類 | 数 |
| --- | --- |
| 英検4級レベル単語 | 300語（うち空所補充に使える語 229語） |
| 会話（大問2＋リスニング第1部） | 30問 |
| 語句整序（大問3） | 24問 |
| 長文（大問4） | 5題 15問 |
| リスニング（第2部・第3部） | 20問 |

## ディレクトリ構成

```
.
├─ web/                 提出対象のWebアプリ（Next.js）
│  ├─ app/              画面とAPIルート
│  ├─ lib/              出題・誤答分類・進捗・発音・プロンプト
│  ├─ data/             英検4級の問題データ + Claude事前生成のコーチパック
│  └─ docs/             提出用ドキュメント
├─ src/, App.js         当初のExpo（React Native）版プロトタイプ ※提出対象外
└─ README.md            このファイル
```

`src/` と `App.js` は、Webアプリに切り替える前の Expo 版プロトタイプです。
**コンペの提出対象は `web/` 配下のみ**で、Expo版はビルドにも動作にも関与しません
（切り替えの経緯は制作メモの「判断1」に記載）。

## デプロイ構成（Vercel）

このリポジトリは2つのアプリを含むため、Vercelでは**別々のプロジェクト**として扱います。

| 対象 | Vercelの Root Directory | ビルド | 出力 |
| --- | --- | --- | --- |
| **提出用アプリ（Next.js）** | **`web`** | Next.js自動検出 | `.next` |
| Expo版プロトタイプ（任意） | `./`（ルート） | `expo export -p web`（Vercelの画面で Build Command に指定） | `dist` |

> ⚠️ リポジトリ直下に `vercel.json` を置くと、Root Directory を `web` にしても
> そちらが優先され Next.js のビルドが壊れます（`expo: command not found`）。
> Expo版を公開する場合は、Vercelプロジェクトの Build & Deployment 画面で
> Build Command に `expo export -p web`、Output Directory に `dist` を指定してください。
>
> ⚠️ Root Directory を `./` のままにすると、Expo版（＝提出対象外）が公開されます。
> 提出用URLを作るときは必ず **Root Directory に `web`** を指定してください。
